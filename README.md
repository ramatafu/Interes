Interes — ваш личный визуальный органайзер в офлайне Interes — это простое и приватное приложение для хранения и организации фотографий по тематическим доскам. Создавайте доски, добавляйте фото, перетаскивайте их в нужном порядке, просматривайте в полноэкранном режиме с зумом и даже выводите изображения поверх других приложений (прозрачное окно). Всё работает полностью офлайн, без интернета. 

✨ Возможности Доски — создавайте неограниченное количество досок с любыми названиями и категориями. Фотографии — добавляйте фото из галереи или файловой системы (без доступа в интернет). Drag‑and‑drop — меняйте порядок фото внутри доски простым перетаскиванием. Полноэкранный просмотр — листайте фото свайпом, увеличивайте жестами (pinch‑to‑zoom) и двойным тапом. Прозрачное окно — выводите любое фото поверх других приложений (на Android — плавающий оверлей, на Windows — окно без рамки с прозрачным фоном). Управление — удаляйте ненужные фото и доски в один клик. Полная приватность — приложение не запрашивает доступ в интернет, все данные хранятся только на вашем устройстве. 

🛠 Технологии Кроссплатформенность — единый код для Android и Windows на Kotlin Multiplatform. Интерфейс — Compose Multiplatform (адаптивный и плавный). База данных — SQLDelight для локального хранения метаданных (доски, порядок фото). Файлы — оригиналы фотографий копируются в приватное хранилище приложения. Офлайн — отсутствуют сетевые разрешения, все операции локальные. 

🖥 Системные требования Android — версия 7.0 (API 24) и выше. Windows — Windows 10/11 (при наличии Java 17+ для запуска через Gradle, или готовый установщик с встроенной JRE). 

📥 Загрузка Android — соберите APK из исходников или скачайте готовый релиз. Windows — используйте desktopApp:run для быстрого запуска или соберите установщик через jpackage.
